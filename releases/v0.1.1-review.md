## 兼容与迁移

- Vault format、Browser RPC 与 Native ABI 无变化。
- Review channel 从 `0.1.0-review` 严格前进到 `0.1.1-review`；桌面通过 `channels/review/latest.json` 更新。
- Android 首次随 Review 发布。已安装 `0.1.0-review` APK 的设备不含更新检查，需要手动覆盖安装本版本；之后的版本经 `channels/review/android.json` 提示。
- Android Debug 包使用 `.debug` application ID，不能被 Release APK 覆盖，两者数据互不共享。

## 已知问题与补偿限制

- 平台 AT 未完成；本版本仅供 Review 验收，不得描述为 Stable。
- macOS 未 notarize、Windows 未 Authenticode 签名，首次打开需按系统提示放行。
- armeabi-v7a 为新增 32 位运行面，尚无真机验证。
- `lintDebug` 存在 3 个既有错误（AutofillStructure、SmsOtpAutofill、Manifest telephony feature），不影响本版构建。
- 回滚：Review channel 不提供降级；问题版本由更高 Review 版本修复。Android release keystore 丢失将无法覆盖升级。
