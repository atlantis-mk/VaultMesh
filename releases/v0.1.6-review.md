| - | REQ-SEC-002、ADR-0053 | fix | ad-hoc macOS 包不再因根钥匙串 ACL 不精确而在每次启动或浏览器填充时重复弹窗 |

`0.1.5-review` 已让同一 Team ID 的签名包使用 Keychain Access Group，并让没有 Team ID 的 ad-hoc 包在创建和更新时只信任包内主程序与 `vaultmesh-native-host`。其后的修复针对仍然反复出现的授权弹窗：文件钥匙串按 `SecTrustedApplicationCopyData` 的不透明身份比较信任应用，主程序身份可以被系统归一化为 `.app`；读取根条目前必须汇总全部 ACL，要求非空信任应用并集恰好是这两个包内可执行文件，且至少一个 PartitionID ACL 存在并且所有 PartitionID ACL 都精确匹配当前 cdhash 分区列表。污染或旧 ACL 只在该根条目内部规范化一次，写后复验；精确 ACL 不再进入写路径。主程序与 Host 用应用支持目录内 owner-only 非秘密文件锁串行检查和读取，同一进程只缓存一次尝试结果。取消或复验失败必须 fail closed，不得删除钥匙串条目，也不得枚举或修改其他软件的条目。`AT-SEC-002` 仍未执行。
