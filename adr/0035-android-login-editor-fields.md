# ADR-0035：Android Login 常规字段与受保护值边界

- 状态：Accepted
- 日期：2026-09-18
- 关联 Work：`CHG-2026-060-android-login-fields`
- 关闭 OPEN：无

## 背景

Android 基础 Login 编辑只有标题、用户名、密码和主网址。core 还保存附加网址、自定义字段、备注、文件夹、收藏与自动填充/复验策略；TOTP seed 和恢复码已有独立受保护操作。

## 决策

- 用户明确打开 Login 编辑器后，固定 `loginEditorDetail` 仅返回常规补充字段和自定义字段；不返回密码、TOTP seed 或恢复码。普通列表继续只返回安全摘要。
- 固定 `addLoginComplete`、`updateLoginComplete` 接受基础字段及严格类型化、有界的常规补充字段，在单次 core mutation 中提交。更新留空密码保留原值，TOTP seed 与恢复码始终由 core 保留；其设置/查看/清除继续使用各自独立操作。
- 取消、切换、后台、锁定或迟到详情必须清除草稿。旧基础操作保留兼容。

## 原因

按需编辑详情满足桌面字段能力，同时保留密码与二次验证资料的独立特权边界；单次提交避免基础字段与填充策略不一致。

## 后果

备注与自定义字段值会在显式编辑期间短时进入 Compose 内存；附加网址和填充策略需跨端与真机验收。

## 被拒方案

- 把补充字段放入普通列表：扩大未请求时的资料暴露面。
- 为普通编辑读取旧密码、TOTP seed 或恢复码：违反已有受保护值边界。
- 分两次保存基础与补充字段：第二次失败可留下部分编辑。

## 验证

`CT-ANDROID-JNI-016`、`AT-ANDROID-018` 与 `GATE-3A`。
