# ADR-0030：Android 受保护字段短时查看

- 状态：Accepted
- 日期：2026-09-18
- 关联 Work：`CHG-2026-055-android-protected-reveal`
- 关闭 OPEN：无

## 背景

Android 已支持受保护字段的显式复制，但用户还需要在手机上查看已保存值。既有 JNI 字段访问逐次验证主密码；普通摘要和编辑仍不能读取秘密。

## 决策

- 查看只复用已有可枚举字段 JNI 值访问：Login 密码、Card 卡号/安全码/PIN、SSH 密码/公钥/私钥/口令及普通 Secret 值。每次动作重新验证主密码；Passkey 和缺失字段仍由 core 拒绝。TOTP 当前代码不进入此静态值查看入口。
- Kotlin 在用户提交前从 Compose 状态清空主密码；成功后仅当前前台弹窗持有一个值，30 秒后关闭。关闭、切换、后台化、锁定或迟到响应必须清除值，不保存到 Bundle、SavedStateHandle、日志或列表。Activity 保持 `FLAG_SECURE`。
- 查看不自动写剪贴板，不增加通用 reveal DTO 或额外 JNI router。长值在弹窗按需分块渲染，范围受既有字段访问上限约束。

## 原因

复用已审核的字段鉴权与有界返回可避免第二套秘密授权逻辑；明确查看和短时 UI 持有是与复制不同的用户动作。

## 后果

值在显示期间进入 JVM/Compose 内存，JVM 字符串无法可靠原位擦除。`FLAG_SECURE` 不阻止周围人员或所有辅助功能读取屏幕，真机须验证窗口、后台与超时行为。

## 被拒方案

- 将秘密加入普通列表或编辑详情：扩大无请求时的暴露面。
- 查看时直接复制到剪贴板：不满足屏幕查看意图并扩大系统级暴露面。
- 持有可复用解锁令牌：破坏每次主密码验证要求。

## 验证

`CT-ANDROID-REVEAL-001`、`AT-ANDROID-013` 与 `GATE-3A`。
