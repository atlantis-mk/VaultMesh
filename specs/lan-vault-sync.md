# 局域网 Vault 自动同步

## LAN-SYNC-001 数据与合并

仅已授权且双方 desktop 解锁的同链路 macOS/Windows 客户端可以同步。Login/TOTP/恢复码、card、SSH、identity、Secret、Service、API environment 及其 trash/history 必须按 kind + UUID 同步。旧 BE=0 Passkey、邮件连接凭据、审计、设备设置、Agent/Browser 权限、内部 connector、SSH 本机部署绑定不得同步。不同 UUID 保留独立条目。

Core 必须为每个同步记录持久化 HLC 和副本 ID，整记录采用确定性 LWW，败者保留在加密冲突历史。同版本重复收取必须幂等；编辑、永久删除、历史清理必须同事务记录版本和不含秘密的 tombstone，首版不得自动回收墓碑。历史清理还必须持久化按条目的 HLC 清理版本，丢弃版本不高于它的历史，覆盖清理时尚未见过的离线历史；冲突历史使用全局清理版本。回收站与活动记录必须共享同一逻辑条目键，避免复活。引用失效时必须 fail closed，不能继续沿用旧 target 或已批准计划。

## LAN-SYNC-002 授权与网络

新配对界面必须说明配对即授权当前 Vault 的双向同步；旧配对双方必须各确认一次。授权必须绑定双方 Vault 和已固定证书的设备身份。首次绑定以已授权的认证连接交换 Vault 身份。切换或恢复 Vault 后不得沿用旧绑定。同步协议独立版本化，使用 mutual TLS、大小/数量/超时限制，版本清单和变化记录仅存在 Rust 敏感内存。首版每帧/批次上限 16 MiB、同步记录上限 100,000、设备/发现队列上限 32、并发连接上限 8；连接 IO 超时 10 秒、总时限 30 秒。超限必须失败且不部分落盘。

服务必须独立于页面在 desktop 解锁期间自动发现、重连和同步。配对发现仍保持显式十分钟窗口；同步发现不得公开持久设备/Vault 标识。桌面锁定、系统锁定、睡眠、退出或撤销必须立即关闭连接、取消未提交事务并清除敏感缓冲区。Browser/Agent 解锁不得延长同步。接收记录必须与当前本地修改重合并，原子提交成功后才能确认；重复或确认丢失必须可重试。关闭同步不删除副本。
