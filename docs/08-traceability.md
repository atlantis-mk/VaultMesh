## 更新规则

- 任一 Requirement/AT/CT ID 不得只出现在一侧；新增、替代或移除必须同步主规格和本表。
- `Pass` 必须引用最近适用版本的证据；测试范围缩小时拆分状态，不能保留聚合 Pass。
- `Blocked` 必须指向 `OPEN-*`、Work ID 或外部 Gate。
- Bug 修复前失败、修复后通过的证据写入 BUG Change，并在适用时更新状态。
- Release 记录引用本表和证据，但不重新定义 Requirement。
- Agent 只读取当前 Requirement/Test 对应行；只有状态冲突或范围缺口才扩大到其他行。
